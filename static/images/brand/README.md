# COOPMS Brand Assets

Final approved direction: confident navy blue, white, and a restrained yellow accent.

## Files

- `coopms-logo.svg` - primary horizontal logo.
- `coopms-logo-lockup.svg` - formal logo with tagline bar.
- `coopms-mark.svg` - icon-only mark for app icons and compact placements.
- `coopms-favicon.svg` - favicon-safe mark on navy tile.
- `coopms-logo-reverse.svg` - logo for dark/navy backgrounds.
- `coopms-logo-monochrome.svg` - one-color logo for restrained documents and stamps.
- `coopms-logo-lockup-preview.png` - generated visual preview of the approved lockup direction.

## Brand Text

- Wordmark: `COOPMS`
- Tagline: `Digital Cooperative Management Platform`

## Colors

- Navy: `#082B66`
- Yellow accent: `#F4B51C`
- White: `#FFFFFF`

## Usage Notes

Use the primary logo inside the app header and documents. Use the lockup for pitch decks, proposals, email headers, and formal brand pages. Use the icon-only mark for favicon, sidebar collapse states, and mobile app-style placements.
